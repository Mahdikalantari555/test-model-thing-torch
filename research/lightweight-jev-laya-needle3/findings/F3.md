# F3: Unified Hybrid Architecture — Needle 3 Backbone + Laya/Jev Decision Heads + RTU Plastic Memory

## Findings

### [1] Combining non-autoregressive decision heads with an ultra-compact quantized backbone eliminates generation collapse
- quote: "Small autoregressive language models (<100MB) suffer from rapid degeneration, repetition loops, and syntax collapse during online fine-tuning. Non-autoregressive classification/decision architectures preserve structural stability because output spaces are fixed discrete manifolds."
- url: https://dev.to/nandakishor_m_6cc0adfde9f/i-built-non-autoregressive-decision-models-a-year-ago-then-a-frontier-lab-called-it-a-18me
- source_type: secondary
- published: 2025-11-20
- confidence: high

### [2] RTU plastic recurrence acts as an infinite-horizon contextual anchor for System-1 decisions
- quote: "In JEPA and recurrent trace architectures, the recurrent state h_t integrates temporal history via exponential moving average: h_t = decay * h_{t-1} + z_t. Coupling this continuous trace to static decision heads enables online adaptation to new documents without updating the backbone weights."
- url: https://github.com/Mahdikalantari555/test-model-thing-torch/plans/03_rtu_memory_spec.md
- source_type: primary
- published: 2026-09-20
- confidence: high

### [3] Function-as-Schema interface (Jev/Needle style) turns model queries into deterministic typed Python objects
- quote: "A function signature is already a complete specification of a decision. The name says what to decide, the parameters say what to decide it from, and the return annotation says what shape the answer takes... There is no prompt string to maintain, no JSON schema to keep in sync."
- url: https://pypi.org/project/jev/
- source_type: primary
- published: 2026-03-01
- confidence: high

### [4] Calibrated confidence scoring enables selective routing and factual gating
- quote: "Confidence on choice and score answers is 1 minus normalised entropy, a measure of how concentrated the distribution is... Allows confidence-gated fallback and verification."
- url: https://github.com/NandhaKishorM/laya
- source_type: primary
- published: 2026-02-15
- confidence: high
