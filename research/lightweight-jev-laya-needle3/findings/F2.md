# F2: Needle 3 (Cactus Compute) 8–29 MB On-Device Foundation Architecture

## Findings

### [1] Needle 3 is a single 8–29 MB binary designed for extreme edge execution
- quote: "A foundation model for mobiles, wearables, robots, smart home, automotive and microcontrollers. The whole model is a single 8-29 MB binary built on our Simple Attention Network."
- url: https://github.com/cactus-compute/needle
- source_type: primary
- published: 2026-01-10
- confidence: high

### [2] Needle 3 deliberately trades open-ended chat generation for hyper-accurate option selection and tool calling
- quote: "we trade general chat capacity to beat models 10x its size on mobile tool calls and match 2-3x bigger models on extraction."
- url: https://github.com/cactus-compute/needle
- source_type: primary
- published: 2026-01-10
- confidence: high

### [3] Architecture uses Laddered Simple Attention, Monarch Hadamard MLPs, and Engram memory
- quote: "Needle 3 is a Laddered Simple Attention Network: a Monarch Hadamard MLP in place of the FFN, GQA attention with causal conv taps, engram n-gram memory read by gather, and multi-lane hyper-connections... Most of its parameters sit in the engram, so the 121M model does the arithmetic of a 50M one."
- url: https://cactuscompute.com/needle
- source_type: primary
- published: 2026-01-15
- confidence: high

### [4] Needle 3 incorporates learned confidence heads and grammar constraints
- quote: "A byte-level grammar compiled from your schemas constrains every token, and every response carries a calibrated confidence score from a learned head."
- url: https://huggingface.co/Cactus-Compute/needle3
- source_type: primary
- published: 2026-02-01
- confidence: high

### [5] Needle 3 supports native Python function decoration for tool execution
- quote: "Decorate a function: the signature gives the argument types, the docstring is the tool description, and run() completes the loop, executing your function and returning its results."
- url: https://github.com/cactus-compute/needle
- source_type: primary
- published: 2026-01-10
- confidence: high
