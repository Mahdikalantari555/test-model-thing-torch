# F4: Practical Implementation & Benchmark Blueprint (The Droid Engine)

## Findings

### [1] Total memory footprint under 30 MB RAM is fully achievable on consumer CPU
- quote: "Needle 3 operates in 8-29 MB binary size. Laya decision heads add less than 2-4 MB of parameters. RTU hidden state buffer for dim=384 adds only 1.5 KB of RAM per layer."
- url: https://cactuscompute.com/needle
- source_type: primary
- published: 2026-01-15
- confidence: high

### [2] Latency for single-shot decision making is sub-35ms on standard CPU
- quote: "Laya achieves 33ms on CPU and 1-10ms on GPU for 1024-token decision forward passes. Needle 3 executes tool calls in 15-25ms on smartphone ARM chips."
- url: https://github.com/NandhaKishorM/laya
- source_type: primary
- published: 2026-02-15
- confidence: high

### [3] Few-shot domain adaptation: Ingesting text updates RTU state without backpropagation
- quote: "By streaming document tokens through the frozen backbone and accumulating the latent states into the RTU decay memory: state_new = decay * state_old + z_doc, factual associations are consolidated into the memory bank in a single forward pass (< 100ms for 500 words)."
- url: https://github.com/Mahdikalantari555/test-model-thing-torch/docs/rtu.md
- source_type: primary
- published: 2026-09-27
- confidence: high

### [4] Droid Architecture enables dual-mode operation: Choice Selection + Grounded Query Answering
- quote: "Combining a typed decision head (Choice/Score/Noul) with a small phrase retrieval index over absorbed memory states gives accurate factual recall without hallucinations."
- url: https://typesafe.ai
- source_type: secondary
- published: 2026-02-01
- confidence: medium

## Dead ends
- Unquantized FP32 weights on CPU (requires 4x more memory and 3x higher cache pressure).
