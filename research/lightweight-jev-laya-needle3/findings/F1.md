# F1: Jev and Laya Non-Autoregressive System-1 Decision Engines

## Findings

### [1] Jev compiles typed Python function signatures into zero-text System-1 decision queries
- quote: "`@jev.fn` turns a Python function definition into a query against Jev, TypeSafe's System One model... Jev generates no text. It answers typed questions about a state (yes/no probabilities, choices, scores) in one parallel call, with calibrated probabilities."
- url: https://pypi.org/project/jev/
- source_type: primary
- published: 2026-03-01
- confidence: high

### [2] Laya implements an open-source, multilingual, non-autoregressive decision engine running in 33ms
- quote: "Multilingual, non-autoregressive System 1 decision engine. Typed decisions over 100+ languages in a single forward pass — 33 ms — trained with reinforcement learning against strictly proper scoring rules (RLCD)."
- url: https://github.com/NandhaKishorM/laya
- source_type: primary
- published: 2026-02-15
- confidence: high

### [3] Non-autoregressive decision models bypass token-by-token generation collapse
- quote: "The shipped checkpoints work zero-shot, but fine-tuning on decisions from your own domain is where accuracy jumps... Laya answers a single request in 10-33ms without autoregressive token generation."
- url: https://dev.to/nandakishor_m_6cc0adfde9f/i-built-non-autoregressive-decision-models-a-year-ago-then-a-frontier-lab-called-it-a-18me
- source_type: secondary
- published: 2025-11-20
- confidence: high

### [4] Jev wire format supports three native decision primitives: Choice, Score, and Noul (boolean)
- quote: "Laya's answer payload is already schema-identical to what Jev returns (choice/score/noul answers and a usage block)... Choice takes the argmax, bool is thresholded, score returns expected value."
- url: https://pypi.org/project/jev/
- source_type: primary
- published: 2026-03-01
- confidence: high

### [5] Laya achieves higher argmax accuracy than Jev on typed decisions
- quote: "On typed-decisions, 2,000 decisions: Laya-typed-decisions achieves 0.766 vs Jev 1.13.0 at 0.727, clearing the teacher self-agreement ceiling."
- url: https://github.com/NandhaKishorM/laya/blob/main/BENCHMARKS.md
- source_type: primary
- published: 2026-02-20
- confidence: high
